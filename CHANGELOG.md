# Changelog

No binaries are published from this repository. Build from source (see the README).

## 1.1.0 — 16 Nov 2026 (Android, versionCode 2)
- Pay-per-delivery bills with a month ledger (milk, newspaper, maid, water cans, tiffin), exact integer money.
- Savings goals, assets and task comments; bulk pantry paste-in; owner/administrator delete controls.
- Assistant grew from 31 to 76 tools (shopping lists, pantry use, budgets, recipes, cleaning, notes, memory, devices, automations, connected services, savings, assets, comments, documents). Invitations, role changes and bill-payment records are approval-only.
- Telegram (outbound, approval-gated) and read-only Google Calendar connectors; plugin SDK docs and manifest validator.
- Fixed: a monthly amount could be stored as a per-unit rate; the assistant now uses a fixed-bill tool and large per-unit bills are held for confirmation.

## 1.0.0 — 16 Nov 2026 (Android, versionCode 1)
- First release: native Android and iOS apps, Firebase backend, MCP tool server, Hermes Mobile and server Hermes, Liquid Glass on both platforms, Connections (devices, automations, Alexa), automatic spending capture, Home Assistant bridge.
